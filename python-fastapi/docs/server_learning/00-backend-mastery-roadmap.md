## 阶段学习方法建议

1. **先抓宏观直觉，再看具体技术**：
   后端知识最忌讳死记硬背名词。牢记**生活比喻**（如“试衣间门栓”、“哲学家就餐对撞”），理解每一个机制在现实世界解决的痛点。
2. **亲手敲代码 + 故意制造破坏测试**：
   在本地起两个终端并发请求，故意复现死锁和数据覆盖，亲眼看数据库抛错，再用锁解决，印象会极其深刻。
3. **保持对“边界与极端情况”的警惕**：
   优秀的后端开发者和普通开发者的唯一区别，就是**对极端并发、网络中断、中间崩溃时数据一致性的预判能力**。
